How to Install in Kodi

  1. In Kodi, navigate to Settings (Gear Icon) > File manager > Add source.
  2. Click <None> and enter this URL: https://black-n-yellow412.github.io/Skynet/
  3. Name the source Skynet and click OK.
  4. Go back to the Home Screen > Add-ons > Box icon > Install from zip file.
  5. Select Skynet and choose repository.skynet-1.0.0.zip.
  6. Once installed, select Install from repository > Skynet Repository > Look and feel > Skin > Skynet.
